# Lance Spearman — Windows PC Demo Release Target

**Target:** January 1, 2027 (planning goal; not a guaranteed release).
**Platform:** Windows PC (Unreal Engine 5.4).
**Scope:** Chapter 1, Level 1, Arrival at the Market — a small but polished playable vertical slice.
**Out of scope for this milestone:** all 70 levels, a complete Chapter 1 with seven polished levels, PlayStation 5, Xbox.

## Minimum release acceptance criteria
- [ ] Unreal Engine project compiles and launches on a Windows PC
- [ ] Game packages as a standalone Windows executable
- [ ] Third-person camera, keyboard/mouse and controller input tested
- [ ] Licensed realistic Lance character with locomotion animation
- [ ] Nairobi market playable area with navigable geometry and collision
- [ ] Mission start, contact interaction, stealth encounter, extraction and end state
- [ ] Guards have readable patrol/detection feedback
- [ ] Clear objective HUD, subtitles and pause/restart
- [ ] Original licensed soundtrack, ambience and basic SFX
- [ ] Save/checkpoint or safe restart behavior
- [ ] Performance, crash and usability playtest completed
- [ ] Distribution rights and third-party asset licenses checked

## Milestones
- Oct 27–Nov 10: Compile and stabilize UE5 Windows project, verify input and basic mission.
- Nov 11–Nov 25: Character, locomotion, licensed Nairobi environment and guard navigation.
- Nov 26–Dec 10: Mission flow, stealth, interaction, extraction and HUD.
- Dec 11–Dec 24: Audio, performance optimization, accessibility and QA.
- Dec 25–Jan 1: Release candidate, Windows packaging and smoke tests.

## Risk and dependencies
A date is a target, not evidence of delivery. Requires an Unreal-capable Windows development machine, UE5 installation, human QA, licensed assets and development time. The current source is uncompiled and the visual assets are placeholders. Reassess schedule immediately after the first successful Windows build.
